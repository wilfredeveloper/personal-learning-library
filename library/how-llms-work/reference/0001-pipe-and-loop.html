The formulas

\[ p_\theta(x_t \mid x_{<t}) \]

A language model: probability of the next token \(x_t\) given all earlier tokens \(x_{<t}\); \(\theta\) = the trainable parameters.

\[ P(x_1,\dots,x_T) = \prod_{t=1}^{T} p_\theta(x_t \mid x_{<t}) \qquad\Longleftarrow\qquad P(A,B) = P(A)\,P(B\mid A) \text{ repeated.} \]

The chain rule of probability: exact, no assumption. The model's choice is only how it computes each factor.

\[ x_t \sim p_\theta(\,\cdot \mid x_{<t}) \quad\text{append, repeat until an end token.} \]

Autoregressive generation: generateText, routes/train-transformer/transformer.ts:832–905.

\[ \log P(x_1,\dots,x_T) = \sum_{t=1}^{T} \log p_\theta(x_t \mid x_{<t}) \]

Work in logs: \(0.5^{200} \approx 6\times10^{-61}\) underflows a 32-bit float (min ≈ \(10^{-45}\)). Minus the average of this is the cross-entropy loss (lesson 8).
